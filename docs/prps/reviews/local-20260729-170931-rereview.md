### HIGH

- **[F013]** `packages/rfapps-cli/src/lib/backup-planner.ts:548` — Destination containment is
  checked against the lexical Compose bind source, so a daemon-side alias can place the destination
  inside the actual archived source and cause recursive growth or disk exhaustion.
  - **Status**: Fixed
  - **Category**: Security
  - **Suggested fix**: Include the local destination in daemon-authoritative topology probing,
    reject identity/equality/containment overlap with every selected bind source, and add an
    alias-containment regression test.

### MEDIUM

- **[F014]** `packages/rfapps-cli/src/lib/backup-storage-write.ts:129` — A reservation failure after
  bundle-directory creation intentionally retains the directory, but the coordinator receives no
  reservation and reports `stagingDisposition: "none"` without the retained `bundlePath`.
  - **Status**: Fixed
  - **Category**: Completeness
  - **Suggested fix**: Propagate a trusted retained-reservation path/disposition for failures after
    directory creation, emit `retained-incomplete` with `bundlePath`, and add a post-creation
    failure regression test.
