**Decision**: REQUEST CHANGES

## Summary

The implementation is well tested and preserves the mutation boundary, but strict config discovery
and parse diagnostics still have two fail-closed/security defects. Additional medium and low findings
strengthen terminal safety, compile-time fingerprint completeness, test coverage, and documentation.

## Findings

### CRITICAL

### HIGH

- **[F001]** `packages/rfmedia-cli/src/lib/config.ts:4843` — Strict discovery uses `pathExists()`, which collapses non-`ENOENT` access failures into absence and can fall through to a lower-priority config. [correctness]
  - **Status**: Fixed
  - **Category**: Correctness
  - **Suggested fix**: In strict mode, continue only on `ENOENT`; surface every other discovery/read failure with the authoritative candidate path and add a non-`ENOENT` regression.

- **[F002]** `packages/rfmedia-cli/src/lib/config.ts:4878` — Strict YAML/JSON parsing rethrows raw parser exceptions after secret injection; source excerpts can disclose resolved secrets and do not reliably identify the config path. [security, correctness]
  - **Status**: Fixed
  - **Category**: Security
  - **Suggested fix**: Replace raw parser exceptions with a sanitized path-bearing `ConfigError` that names only the format and config path, preserves the cause internally, and test that a sentinel injected secret never appears in diagnostics.

### MEDIUM

- **[F003]** `packages/rfmedia-cli/src/lib/bridge/policy-overrides.ts:58` — Fingerprint validation manually mirrors closed domain unions without compile-time exhaustiveness fences, so future valid union members can compile but fail at runtime. [quality]
  - **Status**: Fixed
  - **Category**: Maintainability
  - **Suggested fix**: Add compile-time completeness assertions for every manually mirrored closed union or consume canonical registries where available.

- **[F004]** `packages/rfmedia-cli/src/lib/bridge/policy-overrides.test.ts:165` — Rotation tests do not independently cover every included check field or the unavailable-observation boundary. [quality]
  - **Status**: Fixed
  - **Category**: Completeness
  - **Suggested fix**: Add table cases for signal, comparator, bound, satisfied, configPath, and observed-to-unavailable/reason changes.

- **[F005]** `packages/rfmedia-cli/src/lib/config.ts:2898` — Invalid dynamic override keys/fields are interpolated into diagnostics before rejection, allowing C1 or bidi controls to spoof terminal output. [security]
  - **Status**: Fixed
  - **Category**: Security
  - **Suggested fix**: Escape every dynamic path segment before constructing diagnostics and add C1, ESC, and bidi regressions.

### LOW

- **[F006]** `docs/plans/issue-313-policy-overrides/research-ux.md:13` — UX research retains superseded `SUPPRESSED`/`UNMATCHED` labels and generic hash-replacement recovery. [correctness]
  - **Status**: Fixed
  - **Category**: Completeness
  - **Suggested fix**: Align the research artifact with `ACTIVE SUPPRESSION`, `STALE — REVIEW REQUIRED`, and hash replacement only for evidence-changed records with a current fingerprint.

- **[F007]** `packages/rfmedia-cli/src/commands/lidarr-policy-presenter.ts:54` — Presenter comments still describe proposal/skip-only CSV, explain, and key discovery behavior. [quality]
  - **Status**: Fixed
  - **Category**: Maintainability
  - **Suggested fix**: Update affected comments to include override rows, keys, and active-suppression verbosity behavior.
