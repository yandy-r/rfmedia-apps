## Summary

The sixth independent correctness, security, and quality review found one critical SQLite namespace
race, four unique high-severity freshness/publication/verification gaps, and two medium
resource/contract gaps. The invocation-wide immutable database snapshot was independently rejected
by all three lenses as a per-record freshness guard. A sixth fix cycle and a new approval review
are required before publication.

## Findings

### CRITICAL

- **[W001]** `packages/rfmedia-cli/src/lib/db.ts:411` — SQLite could open WAL/SHM through a mutable
  parent pathname before the immediate transaction pinned the namespace.
  - **Status**: Fixed
  - **Category**: Security
  - **Suggested fix**: Require a trusted stable parent, pin parent and main-file descriptors, open
    the immediate transaction before schema access, and add a deterministic pre-transaction parent
    swap seam.

### HIGH

- **[W002]** `packages/rfmedia-cli/src/actions/reconcile.ts:1021` — Per-record database guards read
  one frozen execution snapshot and could miss an external commit made between records.
  - **Status**: Fixed
  - **Category**: Correctness
  - **Suggested fix**: Read the current exact row inside an identity-pinned transaction immediately
    before the record's first mutation; prove later-row drift receives zero writes.

- **[W003]** `packages/rfmedia-cli/src/lib/reconciliation.ts:241` — A lossy MP3/FLAC `db-wins`
  projection could retain an exact-value conflict while post-apply reported verified.
  - **Status**: Fixed
  - **Category**: Correctness
  - **Suggested fix**: Make postcondition evaluation target-projection-aware and cover MP3, FLAC,
    bad-writer, and server-failure cases.

- **[W004]** `packages/rfmedia-cli/src/lib/tag-writer.ts:568` — MP3 publication and cleanup returned
  to unanchored pathnames after final identity validation.
  - **Status**: Fixed
  - **Category**: Security
  - **Suggested fix**: Pin the parent and use descriptor-anchored source, stage, publication, and
    cleanup operations; verify the stage content snapshot immediately before publication.

- **[W005]** `packages/rfmedia-cli/src/lib/tag-writer.ts:529` — Atomic MP3 replacement preserved
  permission bits but dropped ownership, POSIX ACLs, and extended attributes.
  - **Status**: Fixed
  - **Category**: Quality
  - **Suggested fix**: Copy applicable filesystem metadata to the stage and fail closed if it cannot
    be retained; add platform-capability-aware regressions.

### MEDIUM

- **[W006]** `packages/rfmedia-cli/src/actions/reconcile.ts:276` — Local acquisition could retain
  multi-gigabyte projections and created one promise for every candidate.
  - **Status**: Fixed
  - **Category**: Resource control
  - **Suggested fix**: Use a bounded worker queue and enforce an aggregate local projection budget
    with exact-limit and limit-plus-one tests.

- **[W007]** `docs/features/output-formats.md:420` — Public cancellation docs and the settled feature
  spec omitted SIGTERM exit 143.
  - **Status**: Fixed
  - **Category**: Documentation
  - **Suggested fix**: Document SIGINT 130 and SIGTERM 143 consistently.

### LOW

None.
