## Summary

The independent re-review confirmed that the first fix pass resolved server capability gating,
worker/progress behavior, outcome indexing, read-failure exit semantics, and completion parity.
It also found one unresolved critical database identity race, four high-severity fail-closed,
convergence, cancellation, and scale gaps, plus two medium ordering/documentation inconsistencies.
A second fix and re-review cycle is required before the pull request can be opened.

## Findings

### CRITICAL

- **[R001]** `packages/rfmedia-cli/src/lib/db.ts:340` — The writable opener pins the reviewed inode in one descriptor but independently opens SQLite by mutable pathname, permitting an ABA replace-open-restore swap that leaves SQLite connected to an unreviewed database.
  - **Status**: Fixed
  - **Category**: Security
  - **Suggested fix**: Open SQLite through a platform-safe descriptor-backed or `openat`-style binding to the verified no-follow inode, or verify the identity of the file actually backing SQLite before writes. Add a deterministic race-seam test that swaps only during SQLite open and restores before the path check.

### HIGH

- **[R002]** `packages/rfmedia-cli/src/actions/reconcile.ts:743` — A failed mandatory pre-write file metadata reread blocks only `file-wins`; `db-wins` and `server-wins` can still mutate after current file-plane evidence becomes unavailable.
  - **Status**: Fixed
  - **Category**: Correctness
  - **Suggested fix**: Treat every failed pre-write metadata reread as a typed fail-closed stale/read failure before any target write, regardless of strategy; add db-wins and server-wins zero-mutation regressions.

- **[R003]** `packages/rfmedia-cli/src/lib/reconciliation.ts:607` — File-format rating projection occurs only during execution verification, so preview can authorize unrepresentable zero and post-scan can retain drift for quantized MP3/FLAC values.
  - **Status**: Fixed
  - **Category**: Correctness
  - **Suggested fix**: Carry selected file encoding/scale projection into planning, blockers, intended outcomes, and convergence. Block zero/unrepresentable targets before confirmation and add end-to-end quantized MP3 plus FLAC-scale post-scan regressions.

- **[R004]** `packages/rfmedia-cli/src/commands/reconcile.ts:465` — Production scan/apply paths never supply an `AbortSignal`, leaving documented structured cancellation and exit 130 reachable only from tests or direct callers.
  - **Status**: Fixed
  - **Category**: Completeness
  - **Suggested fix**: Connect the command lifecycle to repository signal handling, preserve completed outcomes for structured cancellation output, and add command-level acquisition and mid-apply cancellation coverage.

- **[R005]** `packages/rfmedia-cli/src/actions/reconcile.ts:897` — Each actionable path reacquires the entire paginated server library and copies the entire database snapshot, producing `actionable paths × library/database size` work at documented limits.
  - **Status**: Fixed
  - **Category**: Performance
  - **Suggested fix**: Add provider-neutral uncached exact-track lookup and identity-pinned exact-row reads for per-record guards, or an equivalently bounded versioned precondition. Add multi-record call-count coverage proving full snapshots do not occur inside the apply loop.

### MEDIUM

- **[R006]** `packages/rfmedia-cli/src/actions/reconcile.ts:1001` — Database-stat outcomes discovered after file rewrites are appended after other paths and are not restored to the engine's stable path/kind order.
  - **Status**: Fixed
  - **Category**: Correctness
  - **Suggested fix**: Apply the stable outcome comparator after all dynamic outcomes are added, or insert them at the sorted position while maintaining indexes; add a two-path post-write stat regression.

- **[R007]** `packages/rfmedia-cli/docs/features/metadata-reconciliation.md:486` — The guide still describes per-file `read-failed` rows in a successful scan even though the fixed action now returns a nonzero acquisition error without a reconciliation result.
  - **Status**: Fixed
  - **Category**: Completeness
  - **Suggested fix**: Document read/parse failure as a nonzero acquisition failure and machine error envelope, removing successful-finding guidance from both affected sections.
