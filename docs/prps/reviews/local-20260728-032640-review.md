## Summary

The report-first reconciliation architecture and its critical contracts are well covered, but the
review found two runtime defects that must be fixed before publication: Bash dispatch omits the new
leaf, and offline scope discovery lets legacy snapshots poison otherwise valid current evidence.
The remaining findings tighten bounded output, shared policy, public typing, focused structure, and
durability coverage.

## Findings

### CRITICAL

_None._

### HIGH

- **[F001]** `packages/rfmedia-cli/src/lib/bridge/cache.ts:763` — Compatible-scope discovery queries every snapshot version and aborts when any matching row is v1, so one legacy row can block selection of one valid v2 scope.
  - **Status**: Fixed
  - **Category**: Correctness
  - **Suggested fix**: Filter discovery by current snapshot and resolver versions before the exact-one rule, while retaining a bounded incompatible-only distinction, and add a mixed v1/v2 regression test.

- **[F002]** `packages/rfmedia-cli/src/lib/shell-completions/bash.ts:204` — The Bash command-state parser does not recognize `reconcile`, so the generated reconciliation option branch is unreachable at runtime.
  - **Status**: Fixed
  - **Category**: Pattern Compliance
  - **Suggested fix**: Add `reconcile` to the parser alternatives and add a behavioral Bash-completion assertion that the subcommand reaches its option branch.

### MEDIUM

- **[F003]** `docs/roadmap-archive.md:27` — The shipped-history row still contains a temporary closing-PR placeholder.
  - **Status**: Fixed
  - **Category**: Correctness
  - **Suggested fix**: Replace the placeholder with the actual closing PR link after the PR is created and before merge.

- **[F004]** `packages/rfmedia-cli/src/actions/lidarr/reconcile.ts:150` — `listCompletePlexArtists` and `executeLive` each combine several lifecycle responsibilities and exceed the review size threshold.
  - **Status**: Fixed
  - **Category**: Maintainability
  - **Suggested fix**: Extract page validation and live acquisition/snapshot construction into focused helpers while preserving cancellation and persistence ordering.

- **[F005]** `packages/rfmedia-cli/src/lib/bridge/cache.ts:1` — The cache module now combines snapshot codec, selector projection, discovery, and SQL CRUD in more than 1,000 lines.
  - **Status**: Fixed
  - **Category**: Maintainability
  - **Suggested fix**: Keep SQL ownership in the cache layer but extract pure snapshot and selector codec logic into a focused bridge cache-codec module, retaining cache boundary tests.

- **[F006]** `packages/rfmedia-cli/src/lib/bridge/reconcile.ts:37` — Reconciliation duplicates the exact artist-name normalization policy owned by the identity mapper, risking policy drift.
  - **Status**: Fixed
  - **Category**: Pattern Compliance
  - **Suggested fix**: Extract one bridge-owned normalization helper and reuse it from mapping and reconciliation with shared regression coverage.

- **[F007]** `packages/rfmedia-cli/src/lib/bridge/reconcile.ts:82` — Outcome projection, snapshot validation, and duplicate derivation contain multiple long multi-invariant helpers.
  - **Status**: Fixed
  - **Category**: Maintainability
  - **Suggested fix**: Extract state projectors, candidate and target consistency validators, and duplicate detectors into focused helpers.

- **[F008]** `packages/rfmedia-cli/src/lib/bridge/reconcile.ts:374` — Contradictory-MBID duplicate projection rescans the target catalog per source and can allocate quadratic output within accepted snapshot bounds.
  - **Status**: Fixed
  - **Category**: Performance
  - **Suggested fix**: Index normalized target titles once, group contradictory sources by title, reuse the index, and enforce a total duplicate-member output budget.

- **[F009]** `packages/rfmedia-cli/src/types/bridge.ts:566` — Result buckets use the broad `ReconciliationItem[]` type instead of preserving their already-defined discriminated item invariants.
  - **Status**: Fixed
  - **Category**: Type Safety
  - **Suggested fix**: Type each report bucket with its exact item type or the narrow union valid for that bucket.

### LOW

- **[F010]** `packages/rfmedia-cli/src/actions/lidarr/reconcile.test.ts:160` — The action suite does not prove that live snapshot replacement failure propagates and still closes the database exactly once.
  - **Status**: Fixed
  - **Category**: Completeness
  - **Suggested fix**: Add one live-mode replacement-failure test asserting error propagation, exact database closure, and no successful result.

- **[F011]** `packages/rfmedia-cli/src/types/bridge.ts:520` — `review-sealed-plan` is exposed in the public suggestion-code union but has no producer, consumer, documentation, or test.
  - **Status**: Fixed
  - **Category**: Maintainability
  - **Suggested fix**: Remove the unreachable v1 suggestion code until a concrete producer is designed.
