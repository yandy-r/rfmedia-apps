# Legacy Plex Behavior Ownership Matrix

## Purpose and exit condition

This document is the deletion gate for the legacy Plex facade and its process-global cache. It maps
every test in the three Task 6.3 legacy suites, plus the six pagination tests already moved by Task
6.1, to an exact replacement suite and test name. It also records protocol behaviors that were
present in the legacy facade but owned primarily by action tests, including scan fallback, rating
result semantics, playlist batching, collection fallback, and mutation invalidation.

The inventory contains 85 current legacy tests:

- 17 in `src/lib/plex.test.ts`;
- 41 in `src/lib/plex-collection.test.ts`;
- 27 in `src/lib/plex-cache.test.ts`.

The six tests from the deleted `src/lib/plex-pagination.test.ts` bring the complete deletion-parity
inventory to 91 test rows. Task 6.2 separately recorded ownership of the deleted legacy filter
evaluator; it is not duplicated here.

**Exit condition: zero unresolved behavior gaps. Status: satisfied.** Every row below has an exact
replacement owner or an explicit, resolved design supersession. No destination test was edited as
part of this audit.
